# Zepto First Buy

Zepto - Design a Digital Widget That Turns First-Time Visitors Into Buyers - CharterScenario / Brand BriefBrand: ZeptoBusiness situation: Zepto's first-time app visitors browse product categories but do not place an order. Funnel data shows a high drop-off between homepage visit and first add-to-cart for new users, while repeat users convert at a much higher rate.Objective: Increase add-to-cart rate among first-time visitors by 15% within one quarter.Target audience: First-time Zepto app visitors aged 22-40 in Mumbai, Delhi NCR, Bengaluru, Pune, Hyderabad, and Chennai who already order from Swiggy, Zomato, or BigBasket but have never placed a Zepto order.Geography: Tier-1 metro cities where Zepto has full 10-minute delivery coverage. No Tier-2 expansion in this phase.Constraints: The widget must work on mobile web without requiring an app download. It must load and respond in under 3 seconds on a standard 4G connection.Problem StatementA first-time visitor does not know if Zepto fits their own shopping habits, so they leave without ordering. Decide what single interactive experience would prove Zepto's value to this visitor within their first minute on the app, and what it should ask them to do next.Task Instructions1. Design one interactive widget or tool that helps a first-time visitor see how Zepto fits their own needs.2. Build a working prototype of the widget using an AI development tool (Claude, Lovable, Bolt, or similar).3. Define the call-to-action shown at the end of the widget and the exact action it triggers.4. Deploy the widget and test it on an actual mobile screen.5. Justify why this widget solves the stated objective better than a generic homepage banner.Deliverables- Live deployed link to the working widget- One-page strategy document (or 3-5 slides) covering: the widget chosen, why it was chosen, how it solves the objective, and the expected user journey and outcomeThings to take care (for you):- Logical structure: the widget journey runs cleanly from input to output to CTA with no missing steps- Business alignment: the widget speaks to the stated objective and target audience, not a generic brand message- Tradeoff reasoning: the write-up shows why this widget was chosen over at least one other option considered- Feasibility: the widget actually works on mobile within the load-time constraint given- Clarity: the reasoning is specific, with no unnecessary steps or vague language
